# Python codes to compute and visualize point count, RMSE, and ground motion velocity along linear infrastructure.

The codes should be run in QGIS IDE. The name of the layers should be set first. There are some QGIS preparation needed before running the codes. All the layers have been unified with same geographic extent and coordinate systems. The layers could be imported from csv, or shp, or gpkg files with ground motion data such as those from the European Ground Motion Service (EGMS) or with export commands in MintPy or SARvey.

Please cite this preprint if you use these codes:

Aminjafari, S., Nilfouroushan, F., Carlvik, F., Darvishi, M., Eriksson, L. E. B., 2026 (preprint). Evaluating the European Ground Motion Service against Local InSAR Analysis along Key Swedish Corridors. EGUsphere. https://doi.org/10.5194/egusphere-2026-3758
